## 🛠 4. Live Hindsight Code Flow Demonstration

### Retain Operation
```python
from app.hindsight_manager import hindsight_mgr

# 1. Retain on-page recommendation into the domain's persistent memory bank
hindsight_mgr.retain(
    bank_id="opensite_io",
    content=(
        "[SEO RECOMMENDATION] Optimize page title for /pricing to include "
        "high-intent keyword 'Developer Infrastructure Pricing'. Expected "
        "ranking boost: Rank #8 -> Top 5."
    ),
    tags=["seo", "title_optimization", "pricing_page"],
    metadata={
        "type": "Recommendation",
        "action": "title_tag_rewrite",
        "target_url": "/pricing",
        "suggested_title": "Developer Infrastructure Pricing | OpenSite"
    }
)
```

### Recall Operation
```python
# 2. Querying past suggestions across sessions
memories = hindsight_mgr.recall(
    bank_id="opensite_io",
    query="What improvements were previously suggested for the pricing page title?",
    limit=5
)

# 3. Generating evidence-backed growth advice
advice = advise("What improvements were previously suggested for pricing?", memories)
print(advice["answer"])
```
